COMPASS DEVS WEBSITE — IMAGE / FILE REFERENCE LIST
========================================================

HOW TO REPLACE AN IMAGE
-----------------------
1. Go to the location shown below.
2. Replace the existing file with your new image.
3. Keep EXACTLY the same filename and extension.
4. Commit and Push with GitHub Desktop.
5. GitHub Pages will update automatically after deployment finishes.

IMPORTANT
---------
The phone test problem was caused by opening HTML locally through Android content://.
On GitHub Pages these files are served normally over HTTPS from assets/images/.

NOTE ABOUT CROPPING
-------------------
If the correct picture is present but is cropped, the image itself may not
need replacing. The relevant CSS uses object-fit. "contain" shows the whole
image; "cover" fills the box and can crop the edges.
