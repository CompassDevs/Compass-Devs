# Compass Devs Website

Static Compass Devs website prepared for GitHub Pages.

## Main files
- `index.html` — website
- `assets/images/` — replaceable website artwork
- `IMAGE-REFERENCES.txt` — map of each image filename and its purpose

## Updating artwork
Replace an image in `assets/images/` while keeping the same filename, then commit and push with GitHub Desktop.
